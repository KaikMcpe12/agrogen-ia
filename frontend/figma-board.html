Como importar este board no Figma

O Figma não aceita arquivos .fig gerados externamente, mas este board foi construído para importação 100% editável via plugin oficial gratuito:

  1. Abra o Figma → Plugins → Procure "html.to.design" e instale
  2. Crie uma nova página em branco e rode o plugin → opção Import from URL (cole a URL pública deste arquivo) OU Import from file (faça upload do HTML)
  3. O plugin importa cada frame como camadas nativas — textos editáveis, vetores, autolayout e cores como estilos
